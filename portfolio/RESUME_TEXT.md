# Формулировки для резюме

## Короткая версия

Разработал MVP системы управленческой финансовой аналитики для салона красоты на Google Sheets и Apps Script: модель данных, финансовые KPI, контроль полноты периода, Owner Desk, аналитика услуг и команды, идемпотентные операции и regression testing.

## Три пункта опыта

- Спроектировал структуру из 31 связанного листа и формализовал расчёт выручки, возвратов, расходов, операционной прибыли и маржинальности.
- Реализовал Apps Script runtime с preflight-проверками, approval-gated записями, защитой от дублей и безопасным повторным запуском.
- Создал Owner Desk и аналитические экраны; финальный demo-сценарий прошёл end-to-end acceptance, а локальный regression baseline составляет 16/16 suites.

## Для GitHub или профиля

Lumiere Salon Control - демонстрационный MVP финансовой аналитики для владельца салона. Проект показывает полный путь от первичных операций и контроля качества данных до финансовых KPI и пользовательских экранов. Использованы Google Sheets, Google Apps Script, JavaScript, JSON contracts и автоматизированные regression tests.

## English version

Designed and built a Google Sheets and Apps Script financial analytics MVP for a salon owner. Implemented a 31-sheet data model, revenue/refund/expense/profit calculations, explicit period completeness, idempotent and approval-gated write operations, owner-facing dashboards, and a 16-suite regression baseline.

## Корректное позиционирование

Используйте формулировки `демонстрационный MVP`, `синтетические данные`, `end-to-end demo`. Не заявляйте production deployment, реальных клиентов, универсальный CRM import или подтверждённый коммерческий эффект.
