# Данные Lumiere Control

## demo

Фиктивные демонстрационные данные для презентации и тестирования.

## imports

Примеры форматов импорта из внешних систем.

Правила:

- не хранить реальные персональные данные;
- не хранить телефоны и электронные адреса клиентов;
- не хранить платёжные реквизиты;
- явно обозначать демонстрационные данные;
- описывать источник и структуру каждого файла.
