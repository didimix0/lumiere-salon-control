# Контрольные наборы Lumiere Control

Каталог содержит 45 машиночитаемых контрольных случаев `CD-001`-`CD-045` для финансового ядра, формул Google Sheets, будущего Apps Script и регрессионных проверок.

Все значения, ID и имена в этих файлах полностью вымышленные. Наборы связаны с [спецификацией контрольных данных](../../../docs/CONTROL_DATA_SPEC.md), [финансовой логикой](../../../docs/FINANCIAL_LOGIC.md) и [физической спецификацией](../../../docs/GOOGLE_SHEETS_SPEC.md).

Каждый JSON использует общую верхнеуровневую структуру: метаданные теста, периоды, настройки, входные таблицы, ожидаемые метрики, проблемы качества, рекомендации, состояния записей и запреты. Проценты хранятся десятичными коэффициентами, даты используют `YYYY-MM-DD`, а отсутствующие значения обозначаются `null`. Деньги, количества и коэффициенты являются JSON numbers.

Допуски: деньги `0.01`, коэффициенты `0.0001`, целые значения `0`. Все ID стабильны и должны быть уникальны внутри файла. Нельзя вручную менять ожидаемые результаты без соответствующего изменения утверждённой спецификации и повторной проверки финансовой логики.

Новый случай добавляется только с новым непрерывным ID, записью в `manifest.json`, полным набором ожидаемых результатов и ссылкой на раздел спецификации.

Эти файлы не подтверждают структуру реальной выгрузки, не содержат реальных данных и не разрешают начинать программную реализацию импорта до исследования обезличенной реальной выгрузки.
