# ADR 0015 — Канонический каталог lookup-групп

**Статус:** Accepted  
**Дата:** 2026-07-13

Единственный машиночитаемый источник перечня lookup-групп — contracts/lookup-catalog.v1.json. Количество вычисляется по уникальным ключам; текстовый счётчик не имеет приоритета над каталогом. SYS_LOOKUPS содержит одну колонку на ключ и повторяет порядок каталога. Импортные группы входят в общий набор; похожие ключи не объединяются автоматически. Новый enumKey сначала добавляется в каталог и нормативную документацию. Текстовые fallback-поля ADR 0013 не становятся lookup-группами автоматически. Значения не являются пользовательскими или финансовыми данными; runtime-заполнение — отдельная задача.

Последствия: расхождение старых 14 колонок устранено, SYS_LOOKUPS получает однозначный порядок, а будущий контракт схем не извлекает lookup-колонки из Markdown.
