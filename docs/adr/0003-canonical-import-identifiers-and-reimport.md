# ADR-0003: Канонический импорт, идентификаторы и повторный импорт

**Статус:** Accepted  
**Дата:** 13 июля 2026

## Контекст

Первый импорт не должен зависеть от конкретной CRM, а повторная загрузка не должна создавать двойной учёт.

## Принятое решение

Используется канонический шаблон Lumiere Control. Для внешних операций ключом служит `source_system + external_transaction_id`, а для строк услуг добавляется `external_line_id`. Ручные операции получают внутренний UUID. Технический отпечаток только предупреждает о возможных дублях и не изменяет операции автоматически.

## Рассматривавшиеся альтернативы

- Интеграция с конкретной CRM.
- Автоматическое объединение по техническому отпечатку.

## Последствия

Поддерживаются CSV, вставка диапазона и подготовленная выгрузка; конкретный формат источника не подтверждён.

## Ограничения

Программная реализация импорта не начинается до исследования обезличенного реального файла.

## Связанные документы

`DATA_MODEL.md`, `MVP_SCOPE.md`, `UX_SPECIFICATION.md`, `ROADMAP.md`.

## Условия пересмотра

Получение файла с иной устойчивой идентификацией или повторным импортом.
