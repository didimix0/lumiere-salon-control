# ADR-0009: Обязательная спецификация контрольных данных

**Статус:** Accepted  
**Дата:** 13 июля 2026

## Контекст

До финансового ядра требуются воспроизводимые сценарии с ожидаемыми результатами.

## Принятое решение

До реализации создаётся отдельная спецификация контрольных данных. Она включает наборы Roadmap и пробелы аудита: скидки, частичный и прошлый возврат, аванс, материалы, все основные схемы выплат, налоги, оплату, аренду, отрицательные результаты, безубыточность, загрузку, план-факт, прогноз, денежный блок, сценарии, дубли, период и корректировки.

## Рассматривавшиеся альтернативы

- Проверять расчёты только на данных первого пилота.
- Создавать наборы после реализации.

## Последствия

Для каждого набора потребуются исходные данные, ожидаемые результаты, статусы качества, рекомендации и крайние случаи.

## Ограничения

Ни демонстрационные данные, ни ожидаемые результаты этим ADR не создаются.

## Условия пересмотра
