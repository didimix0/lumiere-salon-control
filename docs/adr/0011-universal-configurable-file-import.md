# ADR 0011 — Универсальный настраиваемый импорт CSV/XLSX

**Статус:** Accepted  
**Дата:** 2026-07-13

## Контекст

Реальный файл требуется для проверки конкретного источника, но не должен блокировать общий механизм. Финансовое ядро работает только с канонической моделью.

## Принятое решение

Импорт строится через подтверждаемый пользователем mapping profile, staging и канонические таблицы. Staging не участвует в финансовом расчёте; нечёткие совпадения и отпечатки не применяются автоматически. CRM-adapter не входит в решение.

## Последствия

CSV/XLSX и повторное применение профиля входят в MVP; source-specific mapping, API и автоматический upsert требуют реального источника.

## Условия пересмотра

Получен первый реальный формат или требуется интеграция конкретной CRM.
