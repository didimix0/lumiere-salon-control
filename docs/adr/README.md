# Architecture and Product Decision Records

В этой папке будут храниться записи о значимых продуктовых и архитектурных решениях.

Каждая запись должна содержать:

1. Название решения.
2. Дату.
3. Статус.
4. Контекст.
5. Рассмотренные варианты.
6. Принятое решение.
7. Причины.
8. Последствия.
9. Условия пересмотра.

Рекомендуемый формат имени:

`NNNN-short-decision-name.md`

Пример:

`0001-google-sheets-as-first-mvp-platform.md`
