# ADR 0012 — Git-репозиторий и рабочий процесс Apps Script

**Статус:** Accepted  
**Дата:** 2026-07-13

## Контекст

Прежний `.git` был неполным: отсутствовали HEAD, config, objects и refs, поэтому история не читалась. Node.js и npm доступны, `clasp` отсутствует. Проекту нужно воспроизводимое хранение Apps Script.

## Принятое решение

Неполный `.git` сохранён вне проекта, создан новый локальный репозиторий с веткой `main`; remote и commit пока отсутствуют. Исходники будут храниться в `src/apps-script/`, `clasp` станет локальной dev dependency с lock-файлом. Реальный `.clasp.json` не коммитится. Первый проект будет container-bound к `Lumiere Control — DEV`; авторизация выполняется отдельным шагом.

## Последствия

Git снова работает и код можно хранить локально. Прежняя история не восстановлена; remote, baseline commit, `clasp`, авторизация и DEV-книга отложены.

## Условия пересмотра

Найден remote с историей, выбран другой deployment или container-bound перестал соответствовать требованиям.
